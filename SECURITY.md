# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please do not open a public issue. Email dev.ahmed.elsied@gmail.com, or use "Report a vulnerability" on the Security tab of this repository.

Once a fix is ready we will release it, publish an advisory, and credit you unless you prefer otherwise.
